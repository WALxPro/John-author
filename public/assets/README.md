# Assets

Place the supplied files here with these exact names (or edit `src/config/assets.js`):

| File                          | Used in                     |
| ----------------------------- | --------------------------- |
| `logo__1_.png`                | Header, footer, loader      |
| `hope-for-the-wolf-cover.jpg` | Hero, book sections, CTAs   |
| `author-photo.jpg`            | About the Author biography  |
| `author-cutout.png`           | Home + author hero sections |

Every image has a styled fallback, so the site still renders if a file is missing.
The logo works best as a transparent PNG.
